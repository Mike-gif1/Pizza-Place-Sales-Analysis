# Pizza Place Sales Analysis

A comprehensive data analysis project examining a full year of sales data from a fictional pizza place.

## 📊 Project Overview

This analysis explores revenue performance, sales trends, customer demand patterns, and derives actionable business insights using Python and data analysis techniques.

## 📁 Dataset Structure

- **orders.csv** - Order information (order_id, date, time)
- **order_details.csv** - Individual items in each order (order_id, pizza_id, quantity)
- **pizzas.csv** - Pizza specifications (pizza_id, pizza_type_id, size, price)
- **pizza_types.csv** - Pizza categories and names (pizza_type_id, name, category, ingredients)

## 🚀 Getting Started

### Prerequisites

- Python 3.8+
- pip

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Mike-gif1/Pizza-Place-Sales-Analysis.git
   cd Pizza-Place-Sales-Analysis
   ```

2. Create a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Place your data file (Pizza-Place-Sales.zip) in the project root directory.

### Running the Analysis

```bash
jupyter notebook Task_3_Mike_Abanga.ipynb
```

## 📈 Key Metrics & KPIs

- **Total Revenue:** Analyzed across full year
- **Total Orders:** 21,350+ orders
- **Total Quantity Sold:** 48,620+ units
- **Pizza Types:** 32 varieties
- **Average Order Value:** $38.31+

## 📊 Analysis Sections

1. **Peak Hours Analysis** - Identify busiest hours for operational optimization
2. **Weekly Patterns** - Understand day-of-week sales distribution
3. **Top Performers** - Bestselling pizzas by quantity and revenue
4. **Low Performers** - Underperforming products analysis
5. **Category Analysis** - Revenue distribution across pizza categories
6. **Monthly Trends** - Seasonal patterns and yearly trends
7. **Quarterly Performance** - Quarter-over-quarter comparison

## 💡 Key Insights

- Identify peak hours for staffing optimization
- Understand seasonal demand patterns
- Discover bestselling and underperforming products
- Optimize inventory management
- Develop targeted marketing strategies

### Operational
- Increase staffing during peak hours

- Promote bestselling pizzas in marketing campaigns
- Introduce discounts for underperforming products

### Financial
- Focus on upselling and cross-selling
